# Bento Grid

A responsive social-media dashboard built with HTML and CSS, based on the
[Frontend Mentor Bento Grid challenge](https://www.frontendmentor.io/challenges/bento-grid-RMydElrlOj).
The page arranges eight content cards in a single column on smaller screens and
a bento-style CSS grid on desktop.

## View the page

Open `bento.html` in a browser. The page loads its styles from `style.css` and
uses the illustrations in `assets/images/`. There is no build step or package
installation required.

## Responsive layout

- The default layout stacks the cards vertically for mobile screens.
- At `64rem` and wider, CSS Grid places the cards into the desktop layout.
- The reference designs are available in `design/mobile-design.jpg` and
  `design/desktop-design.jpg`.

## Project files

- `bento.html` - page markup
- `style.css` - colors, card styles, and responsive layouts
- `assets/images/` - card illustrations and favicon
- `design/` - mobile and desktop reference images

## Built with

- HTML
- CSS custom properties
- Flexbox
- CSS Grid
- DM Sans from Google Fonts
